# Реплики ментатов, для которых ещё не подключена новая озвучка

Извлечено из ROM проекта. Уже сделанные выбор дома, первое задание (части 2 и 3) и совет первой миссии исключены. Заголовки и имена файлов не нужно произносить. Одинаковые полные реплики одного ментата достаточно записать один раз; назначения перечислены под именем записи. Фразы приведены целиком, в порядке игры, без добавления слов. Исправлено только отображение русских букв и названия Атрейдесов, как в игре.
