# Логистика, графика, сетевой интерфейс — 19.10.2026

## Реализовано
- Исправлен MD/PC enum GetIndexType; харвестер возвращается к действительной площадке НПЗ, при недоступном въезде запрашивает транспорт, включая аварийный carryall. Плавный подлёт/снижение/взлёт, ожидание перед погрузкой.
- Производство двора не сбрасывается при просмотре списка, готовый заказ сохраняется до выбора. Звук установки: именно эффект «Установка», GEMS 70, только после успешного размещения.
- Закрытие старых экранов при выборе миссии; тестовые кнопки кредитов, бессмертия, раскрытия карты. Исправлена двойная обработка клавиатуры пароля.
- Турели используют transparent PNG-атласы; новый кэшируемый туман с плавной полупрозрачной границей.
- Сетевой интерфейс: один сервер, список комнат, компактные команды с добавлением через +, выбор дома, 50 000 кредитов, клавиатура/геймпад/звуки. Просмотр карты без перетаскивания изображения, занятые точки высадки. Автоматическое внутреннее зерно без поля ввода.
- Максимум **4 на 4**. По последнему запросу сгенерированы **12 разных карт**: три ландшафта для каждого формата 1v1 / 2v2 / 3v3 / 4v4 (размеры 96–320 клеток). Формат фильтрует каталог, число мест и высадок, snapshot отдаёт плотные id игроков. 4v4 сохраняет 192² / 256² / 320². Старты у углов (у больших составов по две позиции около угла), органические скальные плато, одинаковая защищённая площадь строительства и одинаковые доступные поля спайса внутри каждой карты. Местного и нейтрального спайса 12–15% карты; `rules.infiniteSpice=true` и `friendlyFire=false` в данных/конфигурации лобби. Движок получил `G.infiniteSpice` для будущего сетевого загрузчика, кампания сбрасывает его в false.
- Наблюдатель допускается только в `playing`, не занимает слот, настройки/высадка закрыты. При `finished`/удалении комнаты просмотр закрывается; подготовлен callback `leaveObservation`.
- Добавлена оплаченная очередь юнитов на каждом заводе (до 20 с активным): списание полной цены при приёме, отсутствие повторного списания во время производства, автоматический следующий заказ, отмена/возврат. В окне A добавляет, C отменяет; справа количество и отмена ожидающих заказов.
- При создании комнаты сначала диалог названия и пароля, затем настройки. Вход игрока/наблюдателя запрашивает пароль, передаёт `host.joinRoom(id,role,password)`; настоящую проверку делает будущий сервер. Пароль не сохраняется в localStorage/логах. Наблюдатель только `playing`.
- Новые эмблемы домов сгенерированы built-in image_gen: `web/src/gfx/assets/frontend/house-crests-modern.png`; подключены к выбору дома и флагам высадки. Промпты/выходы турелей и эмблем: `lobby-image-prompts-2026-10-19.json`. Своя высадка золотая, союзники синие, враги красные, подписи домов.

## Границы реализации
Сетевая часть остаётся визуальным макетом по исходному запросу пользователя. Настоящий сервер, наблюдение за симуляцией и загрузка больших карт ещё не подключены. `NetworkMenu.snapshot()`, `setRooms()`, host `joinRoom(id,role)`, `refreshRooms()`, `leaveObservation()` — граница для следующего агента. Будущему загрузчику применять `rules.infiniteSpice` к `G.infiniteSpice`; настоящий сервер должен проверять запрет огня по союзникам и жизненный цикл наблюдения. Текущий движок пока ограничен картой ROM 64² и старым пулом участников. Android — будущая платформа; сейчас адаптивное окно/тач/клавиатура ПК.

## Дополнение: тактический планшет и новые звуки
- По выбору пользователя сетевой экран оформлен как тактический планшет: тонкая титановая рамка, матовый экран, подписи без тяжёлых плашек, янтарные акценты. Имя/дом скрыты на списке комнат и видны внутри комнаты. Кнопка создания выделена, мягкий блик и свечение отключаются при reduced-motion. Карта увеличена; на средних экранах команды расположены друг под другом, чтобы поля не обрезались.
- Новые процедурные эффекты: лазерный разряд `COMBAT_SFX.LASER_FIRE` (0x80), взрыв коптера/дрона `DRONE_EXPLOSION` (0x81). `web/src/sound/combat-sfx.ts` создаёт детерминированный PCM; Sound кэширует AudioBuffer, ограничивает 12 одновременных источников, использует компрессор, выключает эффекты через настройки/смену банка. ROM-таблицы/музыка не заменены.
- Лазер звучит только при настоящем выстреле после зарядки; дрон — при уменьшении числа оставшихся членов звена/гибели, повторный урон мёртвому и скрытому производимому юниту не создаёт звук.
- Прошёл `tools/verify-combat-sfx.mjs`: форма/уровни PCM без щелчка на границах, игровые события, кэш, полифония, mute/cleanup. WAV для прослушивания: `previews/combat-sfx/{laser-fire,drone-explosion}.wav`. Это те же сэмплы, которые синтезируются в игре. Также прошли целевые `verify-new-units`, `verify-harvester-defense`, `verify-network-ui`, TS/Vite build.
- Скриншоты планшета: `previews/logistics-lobby/tablet-room-list.png`, итоговый вид комнаты сохраняется как `tablet-lobby.png`. Проверка в единственной вкладке, второй звучащей игры не открывали.
