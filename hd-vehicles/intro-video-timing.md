# Тайминг заставки Dune Remaster для видеогенерации

Кадры взяты из заставки проекта на исходном ROM. Частота игрового таймера — 60 кадров/с; указанные времена приблизительные, расхождение между браузерами до 0,4 с. Видео SEGA длится около 3,65 с, но при медленной загрузке ограничивается 240 игровыми кадрами (4 с), поэтому последующие точки могут сдвинуться.

Раскадровка: `previews/intro-storyboard.png`.

## Действие после заставки

Экран выбора дома не запускается автоматически по таймеру. Он появляется после выбора пункта «Новая игра» в главном меню; его отдельный кадр есть внизу раскадровки.

Для генерации держите широкий кадр 16:9, медленный уверенный наезд планеты справа к центру, затем три раздельных пролёта кораблей по очереди: Ордосы → Атрейдесы → Харконнены. После короткой паузы проявите логотип DUNE и пункты меню. Сохраняйте тёмный космос, синие звёзды и тёплую охристую поверхность планеты.
